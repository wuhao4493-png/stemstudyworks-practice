How to solve linear inequalities

Use the same rearranging techniques as with linear equations. Adding or subtracting a number from both sides preserves the inequality sign. Multiplying or dividing both sides by a negative number reverses the sign. This is the critical rule to check in every solution.

Example: dividing by a negative

Take −2x + 3 < 9. Subtract 3 from both sides to obtain −2x < 6. Divide both sides by −2, remembering to reverse the sign: x > −3. Check x = 0: −2(0) + 3 = 3, which is less than 9. Check x = −4: 11 is not less than 9.

Interpreting the result

For an inequality such as x > −3, the boundary value −3 is excluded. For x ≥ −3, the boundary is included. A number line is a useful way to picture the solution set; the generated questions here focus on the algebraic steps rather than interactive graphs.

Practice tips

Try every question yourself before revealing the worked answer. Use the steps to identify which manipulation caused difficulty, then generate a fresh set. If using in class, print and review the questions for suitability.
