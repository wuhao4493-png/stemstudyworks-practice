How to solve GCSE linear equations

Start by simplifying each side of the equation. Expand brackets where needed, collect variable terms on one side, then isolate the unknown using equivalent operations. Always check your answer by substituting it back into the original equation. When an unknown appears on both sides, subtract a variable term first so that only one remains.

Worked example with brackets

Consider 3(x + 2) = 2x + 11. Expand the left side to get 3x + 6 = 2x + 11. Subtract 2x from both sides: x + 6 = 11. Subtract 6 to find x = 5. Checking gives 3(5 + 2) = 21 and 2(5) + 11 = 21.

Common mistakes to avoid

A frequent error is to expand 3(x + 2) as 3x + 2. The 3 must multiply both terms, giving 3x + 6. Another mistake is to move a term across an equals sign without performing the matching operation on both sides. Use written steps to make the operation explicit.

Practice tips
